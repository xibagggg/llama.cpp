# 2026-11-04：v61，文本Q4／视觉Q4上的注意力QK增量优化

**结论：观察到小幅提速，但未通过特征重复一致性验收，不作为已验收候选。** 原严格审计在特征SHA重复断言处失败，脚本和失败证据均保留；下面ABBA表仅为描述性耗时观察，不能据此跳过稳定性问题。全部24个ABBA请求（含预热）文字和tokens与冻结v50相同，仍不能代替视觉特征稳定性。

在v50已实现的27层Q4 down上，进一步优化视觉D72的QK：向量化IME2结果重排、共享一次K打包，并让16个查询共用K面板加载。模型和量化精度均未变。注意力微基准N1008无mask从43.2564降至40.1910ms，减少7.09%；整模型收益以下列正式ABBA为准。

## 代码实际做了什么

1. 原IME2 QK把8×8累积块逐元素加载、缩放、写回。改成32-lane向量gather，取四块中同一行，整体缩放并连续存储；保留逻辑行列和尾部边界。
2. K按每层/head/tile共享打包一次，RVV完成FP16归一化及布局转换；每个worker按需搬入TCM。Q、K乘2^10保护FP16极小值，FP32输出乘2^-20；abs>63或非有限输入回退原RVV。
3. 内核由8查询×32键改为16查询×32键，两组8查询共用4个K面板加载。每K8迭代的K向量加载减半，结果使用8组FP32向量累积；scratch同时覆盖Q打包、K暂存与16×32输出，guard按总量检查。
4. 仅对已满足原打包条件、D72、16head、N≥988、无mask形状启用IME2 QK。小尺寸和mask保留原路径；其他QK布局/数值边界有显式回退。开关默认关闭。激活仍是相应FP16/FP32精度，不新增低比特激活量化。
5. 从v50恢复原PV、默认注意力及诊断实现，清除此前未采用的模式分支；IME路径作为独立模板实例。v59关闭开关的单次合并表文字、tokens和末切片embedding与v50逐位相同，但本轮多次v61 OFF仍复现特征变化，不能宣称默认路径数值稳定或与v50普遍等价。未定位v55历史差异及本轮变化根因。

N1008时临时共享workspace增加约2.27 MiB（K打包和valid标记），按注意力调用复用；每worker额外scratch上限20,480 bytes，计入原TCM容量guard，不缓存常驻权重。微基准和完整推理都包含打包、复制、重排和同步，不只测矩阵指令。

本轮实际执行链为ggml-spacemit→spine/spert 0.6.3→IME2/RVV；TCM用于worker局部的打包、暂存和计算，较大的共享workspace仍在DDR侧。板上安装的SpaceMIT ORT EP 2.0.7不是本轮执行引擎。

## 质量与边界

十个样例完整OCR与v50的文字和完整tokens均相同。四个明确GT合成表：结构4/4、文字70/70、数字34/34；真实渲染见下图，无人工补结构或纠字。v50已有的英文标题末尾圆点遗漏继续存在，本轮没有修复，也没有新增该十例的文本差异。

实际OTSL渲染保存在本地/板端报告及飞书，原图和OCR内容不上传源码仓库。

QK是FP16乘法、FP32累积，但IME2和RVV的归约顺序不同，不保证逐位相同。常规微基准relative L2约2.7e-7，不能外推为模型特征误差；十例最后保存切片embedding relative L2最大0.061456，个别切片相同。多层网络和动态量化可能放大微小数值差异，具体放大机制本轮未定位。此指标不是准确率或置信度。没有证明Q4对Q8/FP16的一般精度等价。

重复特征变化同时出现在OFF和ON，因此不能全部归因于新QK确定性的累积顺序差异。原始SHA、Float32数组（跳过8字节形状头）和相对L2详见feature-repeat-failure.json。文件新鲜度、请求归档SHA及形状已核验，未将旧文件冒充本次输出。正式严格脚本仍失败；summarize_attention_v61_observed.py只汇总耗时，并显式写passed=false。

额外短诊断同一中文扫描表、相同配置与compute0：冻结v50预热1＋正式3的特征4/4与参考相同；v61预热1＋正式3中1次正式特征变化，相对参考L2=0.028910。八次文字/tokens均相同。问题在关闭新QK时也复现，排查重点收敛到v61相对v50的代码/运行行为变化；此小样本不证明v50一般稳定，也未确认它与历史八worker漂移同源。详见repeat-diagnostic.json。

边界微基准覆盖N988/989/1009/1057尾部、N1008非连续layout、mask/整行masked、大值回退和FP16 subnormal输入。9个边界×2状态×3正式=54次，输出有限、输入不变、scratch/output guard通过、每模式重复逐位一致。mask和大值回退与原路径逐位相同；最大观测relative L2<2.69e-7。合成微基准不替代真实文档GT，原始细节见micro-audit.json。

## 当前瓶颈与下一步

本轮下一优先事项是定位重复特征差异：相同文本/视觉Q4模型，分别复查冻结v50与v61 OFF，随后捕获首个变化的层/算子输入输出，区分共享workspace、TCM重用和量化输入变化；不能用文字相同掩盖失败。七worker规避也不是稳定性保证。

稳定性问题澄清后，计算热点仍是PV和softmax。上轮注意力拆分PV约46%、QK约33%、softmax约16%，复制与同步占比较小。本轮没有新profile。应在实际完整attention上评估PV的寄存器/TCM布局、FP16→FP32转换与计算流水，而不是依据独立内核结果直接合入；softmax可评估向量exp、max/sum和重缩放融合，近似算法须单独验质。文本预填充和生成未改，仍限制整页总收益。
