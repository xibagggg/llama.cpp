# CTC 固定权重离线准备，2026-11-06

新增 `scripts/ocr/pack-ctc-linear.py`，将 PP-OCRv5 CTC 的 9 个固定 MatMul RHS 离线转置；执行器支持 graph version 2，原 version 1 保持兼容。全部权重与计算仍为 FP32，4 个动态注意力 MatMul 保持原路径。共享固定权重若有其他消费者，保留原方向数据。

在 x86 构建服务器对两份实际 PDF 的 162 个裁剪，四种宽度分别做 A/B/B/A，共 648 次正式调用。完整概率、文字、置信度和输入保持检查全部通过；两张版面输入的四个完整输出回归通过。RISC-V CTC CLI／共享库交叉编译通过，未在 K3 部署或执行。
