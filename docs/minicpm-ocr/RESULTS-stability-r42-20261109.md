# r42：PC8 初始化收敛与四线程启动实测（2026-11-09）

本轮取得了**模型启动阶段的可复测收益**：同一候选二进制、同一 DDR 对照配置，按加载线程数 **1→4→4→1** 交错启动，每次只请求一张中文小表格。单线程启动均值 **30.738 秒**，四线程 **19.166 秒**，减少 **11.572 秒（37.65%）**。四次的 OCR 全文、完整 74 个输出 token IDs 和视觉特征逐字节相同。

这只验证了新进程加载模型的提速；文件页缓存没有清空，不是重启机器后的冷盘加载测试。请求本身约 16 秒，不能把启动收益称为稳态推理提速。原 TCM 路径整机卡死的根因仍未确认，本轮也未验收为稳定性修复。

## 代码与执行范围

- 将 PC8 的模式、M8、down-M8、多 N panel、预重排、输入复用和复用诊断开关集中缓存，在发布工作任务前由主控线程解析。原来的 PAD/GELU 模板各自首次初始化输入复用选项，可能在 AI 工作核上调用 `getenv` 并等待 C++ 初始化锁。现在工作核读取已初始化值。数值计算、量化公式和权重布局未改。`GGML_SPACEMIT_PC8_HOST_OPTIONS=0` 仅保留为隔离对照入口，默认启用主控预解析。
- 四线程权重加载使用仓库已有的 `GGML_SPACEMIT_OCR_PC8_LOAD_THREADS=4` 实现。本轮完成此前缺少的 K3 板端对照；没有将该已有实现称为本轮新算法。
- 新程序只部署到两个独立实验目录，没有替换系统库、默认 runtime 或模型。未修改 OTA 服务，也未更新飞书。
- 7 个计算核固定为 8、9、10、11、13、14、15，主控绑定 0–7。SPERT 实时优先级为 0，主控准备并锁页协程栈；QK/PV/tail 新流水线均关闭。
- 模型保持文本 Q4 与 padded-down 视觉 Q4；PC8 加载后采用 INT8 内核所需的重定标布局，不能称为逐算子纯 INT4。

源码分支：`opt/ocr-stability-r42-20261109`；提交：`7a65d35d66f9ca12260ccc5d0a85575de822b5c9`。新后端 SHA256 为 `1bb02e3036ec0374b230edcb79ba16efe6bb1a876ccd083306bff512eff7bfbc`。

## 测试与限制

- 新的主控初始化测试通过：7 个模拟工作线程各读取所有 PC8 选项 100 次，选项值正确，工作线程 `getenv` 调用为 0。
- 现有 PC8 并行加载测试通过 64 组，覆盖实际矩阵和不整齐行尾、1/2/4/8 线程、四种舍入模式、零/次正规/正负 scale、输入不变及边界保护。
- RISC-V 后端交叉编译通过，板端运行核验了新后端和既定 SPERT 哈希；C++ 修改适用的 whitespace/EOF/large-file 钩子通过。
- 初次交叉编译缺少新选项头文件包含，补齐后通过；构建脚本的 Git 检查随后按原文件 CRLF 格式修正。旧加载测试用过严的 `-Werror` 编译时触发现有头文件未使用函数和小对象循环复制警告，按原测试方式保留警告后执行通过；新增测试仍使用 `-Werror`。没有改动无关源码压制警告。
- 未重跑仓库中已有依赖冲突的 Python flake8 环境。后端其他历史文件的警告不属于本轮新修改。
- 本轮没有卡死，全部 3 次单节点和 5 次 OCR 进程均完成、退出；这些有限测试不足以证明长期稳定或确定硬件根因。HMP 的 vector 已启用警告仍出现在成功运行中，不能单独作为故障归因。

## 可复用配置与证据

在独立候选 runtime 目录中，先 `source ./config.sh`，再 `source ./config-startup4.sh`，可选中本轮通过验证的主控预解析、4 线程加载和 DDR 对照。该配置包含较慢的 DDR 推理，不能冒充此前 TCM 的约 1.4 秒视觉成绩，也不能直接用于与历史 EP 耗时计算新差距。

本地 `RESULTS.json` 保存逐次记录、ABBA 均值及全量一致性审计；`FINAL-BOARD-STATE.json` 保存最终状态。源码补丁、构建日志、归档哈希及完整识别结果在本目录。旧实验 `STOP.json` 保留，新授权另存 `RESUME-AUTHORIZATION.json`。

收尾仍是同一 boot `f8f81f4a-28ac-445f-b96a-8105ec468776`，无遗留推理进程，18589 测试端口已释放，可用内存约 14.3 GiB，最高温度 52℃。启动优化保留为已实测候选；后续重点仍是取得原 TCM 卡死的内部阶段/内核现场，稳定性通过后再继续稳态内核提速。
